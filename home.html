Why Bitpack.txt_□×

Fewer programs, fewer licenses, fewer requests to IT.

In a company, the small everyday jobs – a PDF to change, two exports to compare, 300 letters to generate, a procedure to document – usually each need a separate program. Each one has its own license, its own installation and, often, needs administrator rights.

Without Bitpack

  • One program for PDF, another for images, another for video, another for reports.
  • Paid subscriptions and licenses for each of them, for each person.
  • Installation waits for IT, because it needs administrator rights.
  • Documents go through online conversion sites, company data included.
  • Every program looks and works differently, so people have to be trained every time.
  • Small jobs go through the command prompt or PowerShell, which many companies block.

With Bitpack

  • One program, with more than 100 tools ready to use.
  • One file to copy to the computer, with no installation.
  • It runs on a normal user account, with no administrator rights.
  • It starts no Windows programs: no command prompt, no PowerShell, nothing for IT to block.
  • Working data stays in the program's folder, on your own computer.
  • All the tools share the same interface: learn one and you know them all.
Usage scenarios_□×

Where Bitpack is used, and why

Bitpack goes where the work is: a locked-down office PC, a technician's USB stick, a server share. These are the everyday situations it is made for, with the tools used and the technical points behind them.

  • Locked-down PCsStandard user, no installation, cmd and PowerShell blocked – Bitpack needs none of them.
  • Damaged systemsIt reads the PC through Python and psutil, not WMI, PowerShell or the registry.
  • No licence per toolPDF, documents, comparisons, APIs, SQL, monitoring and tickets in one file.
  • Data stays insideDocuments are processed on the PC; everything is kept in a local database.
  • One way of workingThe same windows, menus and shortcuts everywhere: one training.

1IT support on a locked-down PC

A user's PC is slow or a program fails; the technician has no administrator rights there, and the command prompt and PowerShell are blocked.

  • Hardware Monitor, Process Viewer, System Information: load of processor, memory, disk and network, and who uses it
  • Disk Utility and Junk File Manager: what fills the disk, and what can go
  • Terminal: ipconfig, netstat -o, tasklist, systeminfo, ping, nslookup
  • Step Recorder: the fix documented with screenshots, for the Knowledge Base
Technical pointsSystem data comes from psutil, and the terminal commands are answered by Bitpack, so a policy that blocks cmd.exe and powershell.exe does not stop them. Runs as a standard user, nothing installed.

2Starting or running a small IT department

One to five people support 20 to 300 workstations, with no budget for a service desk suite.

  • Ticket System: areas, Level 1 / Level 2, triage, SLA, history, Excel export
  • Knowledge Base and Step Recorder: procedures written once, found by search
  • Shift Planner: the support and on-call schedule, with rest and hour rules checked
  • Copy App and Smart Backup Tool: kits copied from servers with saved profiles, folders backed up
Technical pointsEach Bitpack copy keeps its data in one SQLite database (Config/dbo_bitpack.db); it can be exported and imported, or backed up by copying the Config folder.

3Watching the network services

The team wants to know about a dead share, an offline printer or an expiring certificate before the users call.

  • Network Monitor: each device watched on the service that matters – 445 shares, 3389 remote desktop, 1433 SQL Server, 9100 printers, 554 cameras
  • Web pages checked for their answer and for a text on the page; DNS names for their address
  • Up / Warning / Down, response time, uptime for 24 hours and 7 days, a beep, a report for Excel
  • Port Scanner: the open ports of a server, added to the monitor with one click
Technical pointsTCP connections, web requests and DNS lookups made by Python; Down only after a set number of failed checks; HTTPS certificates verified, with a warning days before they expire.

4Office work without extra licences

Departments change PDFs, produce personalised documents and compare exports, and not every PC has Office.

  • PDF Editor, PDF Tools, Bulk PDF Converter: PDFs edited and many files converted at once
  • Document Merge: one Word template + an Excel table = one contract, certificate or letter per row
  • Excel Compare: two exports compared by a key column, differences in an Excel report
  • Chart Builder and Report Designer: charts and reports from Excel, CSV or SQLite
Technical pointsWord, Excel, PowerPoint and PDF files are read and written by libraries inside Bitpack (python-docx, openpyxl, python-pptx, PyMuPDF, reportlab); documents never go to online converters.

5Data, integration and development work

An engineer has to test an API or look into a database on a PC where Postman, a database client or an IDE cannot be installed.

  • API Tool: HTTP requests, saved headers and bodies, JWT authentication
  • SQLite tools: management studio, executor, diagram, designer, comparison
  • Code Beautify, Hex Editor, Regex Tester, Universal Converter
  • Python IDE: small scripts written and run inside Bitpack
Technical pointsThe database tools work with SQLite files; the API Tool reaches whatever address you give it, from the user's own PC.

6Training and documentation

New colleagues have to learn the procedures, and the procedures have to stay written down.

  • Step Recorder: F9 at every step, arrows, numbers, blur on sensitive data, then Word or PDF
  • Video Editor and Screen Recorder: short training videos
  • Quiz Maker and Quiz Test: a check of what was learned
  • Knowledge Base: everything in one searchable place
Technical pointsScreenshots and recordings stay on the PC; procedures are saved as files and exported to Word or PDF.

7A portable kit for the field

A technician works in shops, branches or at customers, often with a slow connection or none.

  • The Bitpack folder, after the first setup, carried on a USB drive or a server share
  • Most tools work offline
  • System Compatibility Check: a PC verified before work starts
  • Automatic and Manual Repair when Bitpack itself is damaged
Technical pointsEverything Bitpack keeps is in the Config folder next to the Bitpack file; copying the folder moves the tools and their data together.

System Properties – Technical?×

Under the hood

What IT departments usually ask before they let a program on their PCs.

  • One file, built with PythonA precompiled x64 Windows program. The libraries are inside: psutil (system data), Pillow (pictures), PyMuPDF and reportlab (PDF), python-docx, openpyxl and python-pptx (Office files), OpenCV (video).
  • One local databaseSQLite, in Config/dbo_bitpack.db next to the Bitpack file. Each tool keeps its own tables there. Backup: copy the Config folder, or export the database.
  • Standard user, nothing installedNo administrator rights, no installer, no services, no drivers. Removing Bitpack means deleting its folder.
  • No Windows programs, no registryBitpack starts no Windows program and does not read the registry: system information comes from Python and psutil, and the terminal commands are answered by Bitpack itself.
  • Network only where neededOnly the tools that work with the network connect: the Network Monitor, the API Tool, Mail Express and copying from servers – and only to the addresses you give them.
  • Access per toolEvery tool opens with its own account, so each person gets only the tools they need.
  • RequirementsWindows 10 or 11, x64; 4 cores (or 2 cores with 4 threads), Intel Core 4th generation or AMD Ryzen; 4 GB RAM; 500 MB of disk. A built-in check verifies the PC.
  • Approved-programs policiesWhere only approved programs may run (AppLocker, WDAC), the Bitpack file has to be approved once by IT.
Limitations.txt_□×

Limits worth knowing before you start

Bitpack covers the everyday work of an office, not everything. First the limits that apply to every tool, then those of each tool, grouped like the tool list above.

  • Windows onlyBitpack runs on Windows 64-bit. It does not run on macOS, Linux, 32-bit Windows or in a browser.
  • Data stays on each computerEvery copy keeps its own local database. Two computers do not share projects by themselves, and there is no real-time co-editing. For a backup, copy the program's folder.
  • English interfaceMenus, windows and messages of the tools are in English.
  • One login per toolEach tool opens with its own account, so the accounts have to be set up before people start.
  • Not a full Office replacementBitpack creates and reads Word, Excel, PowerPoint and PDF files, but it is not Word or Excel: macros and advanced formatting are not supported.
  • Some tools need a networkSending e-mail, testing APIs, the Network Monitor and copying from servers need a connection. Everything else works offline.
  • One fontEach tool uses one built-in font; there is no font picker.
  • No Windows commandsBitpack starts no Windows program (command prompt, PowerShell, wmic, netsh, powercfg, shutdown…). Common commands such as ping, ipconfig, dir or tasklist are answered by Bitpack itself; anything else is refused.
Documents and PDF
PDF Editor
  • Scanned PDFs are pictures: their text cannot be edited (no text recognition).
  • Export to Word may not keep complex layouts exactly.
Document Merge
  • The template must be a Word .docx file with {{Field}} placeholders.
  • Data comes from Excel (.xlsx) or CSV files: one document per row.
  • Word and PDF output both work without Office; complex Word layouts (text boxes, shapes) may look a little different in the PDF.
Bulk PDF Converter
  • Word files keep text, headings, lists, tables and pictures; text boxes, shapes, charts, SmartArt, footnotes and columns are not reproduced.
  • RTF and ODT files keep only the text and the headings.
  • Old formats (.doc, .xls, .ppt, .ods, .odp) are skipped: save them as .docx, .xlsx or .pptx first.
  • Excel sheets become tables; PowerPoint slides keep only an approximate layout.
  • Binary files are skipped; other text files are printed as plain text.
Step Recorder
  • Steps and documents are in English only.
  • Projects are saved in Bitpack's own .sr95 format; export to Word or PDF.
Bitpack Office
  • A lighter editor than Word and Excel: no macros and no advanced formatting.
Advanced Notepad
  • Plain text only: no bold text, pictures or tables.
  • One built-in font.

Report Designer

SQL Manager Studio Pro

  • Only the commands HELP lists: no pipes, redirection, scripts or other programs.

  • No agents and no SNMP: it checks what answers on the network (TCP ports, web pages, DNS).
  • The Port Scanner scans one device at a time; ports behind a firewall that drops packets show as "no answer".
Ticket System

Frequently asked questions

Where do I get Bitpack?
Download the Bitpack file (Windows 64-bit). It is the whole program: copy it to any folder and run it.
Does anything need to be installed?
No. Bitpack is a single precompiled file for Windows 64-bit. Copy it to the computer and run it.
Do I need administrator rights?
No. Every tool works on a normal user account.
Does Bitpack run Windows commands or scripts?
No. Bitpack starts no Windows program: no command prompt, no PowerShell, no scripts. The commands its terminals and tools need (ping, ipconfig, tasklist, systeminfo and others) are answered by Bitpack itself, so it also works where the company blocks the command prompt and PowerShell.
Do I need Microsoft Office?
No. Bitpack creates and reads Word, Excel, PowerPoint and PDF documents by itself, without Office installed.
Where is the data kept?
In a local database in the program's folder, on your computer. Projects, settings and history are not uploaded to a cloud.
Does it work without the internet?
Yes, except the tools that really work with a network: sending e-mail, testing APIs, the Network Monitor and copying from servers.
Can Bitpack replace our monitoring system?
For a small or medium network, the Network Monitor covers the everyday checks: shares, remote desktop, databases, printers, cameras, web pages, certificates and DNS, with uptime and alerts on screen. It is not an enterprise monitoring system: no agents on the servers, no SNMP, no automatic discovery, and it checks while it is open.
Will it run on our locked-down PCs?
Yes, on standard user accounts and where the command prompt and PowerShell are blocked. If the company allows only approved programs (AppLocker, WDAC), the Bitpack file has to be approved once by IT.
Why does it look like Windows 95?
Because the classic interface is clear and easy to learn: windows, menus and buttons that everybody recognizes. Every tool uses it the same way.
