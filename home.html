Why Bitpack.txt_□×

Fewer programs, fewer licenses, fewer requests to IT.

In a company, the small everyday jobs – a PDF to change, two exports to compare, 300 letters to generate, a procedure to document – usually each need a separate program. Each one has its own license, its own installation and, often, needs administrator rights.

Without Bitpack

  • One program for PDF, another for images, another for video, another for reports.
  • Paid subscriptions and licenses for each of them, for each person.
  • Installation waits for IT, because it needs administrator rights.
  • Documents go through online conversion sites, company data included.
  • Every program looks and works differently, so people have to be trained every time.

With Bitpack

  • One program, with more than 100 tools ready to use.
  • One file to copy to the computer, with no installation.
  • It runs on a normal user account, with no administrator rights.
  • Working data stays in the program's folder, on your own computer.
  • All the tools share the same interface: learn one and you know them all.

Limits worth knowing before you start

Bitpack covers the everyday work of an office, not everything. First the limits that apply to every tool, then those of each tool, grouped like the tool list above.

  • Windows onlyBitpack runs on Windows 64-bit. It does not run on macOS, Linux, 32-bit Windows or in a browser.
  • Data stays on each computerEvery copy keeps its own local database. Two computers do not share projects by themselves, and there is no real-time co-editing. For a backup, copy the program's folder.
  • English interfaceMenus, windows and messages of the tools are in English.
  • One login per toolEach tool opens with its own account, so the accounts have to be set up before people start.
  • Not a full Office replacementBitpack creates and reads Word, Excel, PowerPoint and PDF files, but it is not Word or Excel: macros and advanced formatting are not supported.
  • Some tools need a networkSending e-mail and testing APIs need a connection. Everything else works offline.
  • One fontEach tool uses one built-in font; there is no font picker.
Documents and PDF
PDF Editor 95
  • Scanned PDFs are pictures: their text cannot be edited (no text recognition).
  • Export to Word may not keep complex layouts exactly.
Document Merge
  • The template must be a Word .docx file with {{Field}} placeholders.
  • Data comes from Excel (.xlsx) or CSV files: one document per row.
  • Word output works on its own; PDF output needs Microsoft Word or LibreOffice on the computer.
Batch PDF converter
  • Word files get an evaluation watermark from the converter library.
  • Old formats (.xls, .ppt, .ods, .odp) are skipped: save them as .xlsx or .pptx first.
  • Excel sheets become tables; PowerPoint slides keep only an approximate layout.
  • Binary files are skipped; other text files are printed as plain text.
Step Recorder 95
  • Steps and documents are in English only.
  • Projects are saved in Bitpack's own .sr95 format; export to Word or PDF.
Bitpack Office
  • A lighter editor than Word and Excel: no macros and no advanced formatting.
Advanced Notepad 95
  • Plain text only: no bold text, pictures or tables.
  • One built-in font.
Data and reports
Excel Compare 95
  • Both files need a common key column to match the rows.
  • The report is an Excel file.
Chart Builder 95
  • Data from Excel or CSV files.
  • Exported charts are files: they do not update when the data changes.
Report Designer 95
  • Data from SQL databases, Excel or CSV; output as PDF.
  • Report layouts are saved in Bitpack's own .rep95 format.
SQL Manager Studio Pro
  • SQLite databases only (not SQL Server, MySQL or Oracle).
Diagram Editor 95
  • Opens and saves only its own .diagram95 files (no Visio or other diagram formats).
Images and video
Video Editor 95
  • Export to AVI keeps the sound, but the files are large (up to 4 GB per video).
  • Export to MP4 has no sound.
  • Music: MP3, WAV, OGG and FLAC (not M4A or WMA).
  • Some phone videos (HEVC / H.265) may not open.
  • The original sound of video clips is read through Windows and may not be available on every computer; the music always works.
Paint 95
  • One picture at a time, without layers, like the classic Paint.
Batch image resizer
  • Changes the size only: no cropping or retouching.
  • Overwriting the originals cannot be undone; saving to another folder keeps them.
  • JPG pictures lose a little quality at every save.
Icon Editor 95
  • Icons are drawn pixel by pixel: made for small icons, not for photos.
ICO Converter
  • Produces Windows .ico icons only.
Files and archives
Archive Browser
  • ZIP and TAR archives, including .tar.gz, .tar.bz2 and .tar.xz (not RAR or 7z).
  • Previews text files as text and other files as a hex dump.
Folder Recipe
  • Creates the folders only, not the files inside them.
Batch text editor
  • Plain text files only (not Word, Excel or PDF).
  • Files are read with the encoding you choose; files saved in another encoding can show wrong characters.
  • Changes are written into the files: keep the .bak backup option on to be able to go back.
For IT
Code Beautify 95
  • XML, HTML, CSS, JavaScript, JSON and SQL only.
API tester
  • No AWS Signature or NTLM authentication.
  • Needs a network connection.
File compare
  • Text files only (not Word, Excel or PDF).
BuildIt 95
  • Builds Python (tkinter) program interfaces only.
Everyday
Bitpack desktop
  • Starts the Bitpack tools; it does not replace the Windows desktop or start other programs.
Sticky Notes 95
  • Notes are kept on that computer only.
Mail Express
  • Needs a network connection and an e-mail account.
Shift Planner 95
  • One shift per person per day.
  • Public holidays are not built in: you add your own once and copy them to the next year.
  • It checks rest, days in a row, weekly hours and staffing; it does not calculate pay.
  • Plans are exported as Excel or PDF; they cannot be read back from those files.

Frequently asked questions

Where do I get Bitpack?
Download Bitpack.exe (Windows 64-bit). It is the whole program: copy it to any folder and run it.
Does anything need to be installed?
No. Bitpack is a single precompiled file for Windows 64-bit. Copy it to the computer and run it.
Do I need administrator rights?
No. Every tool works on a normal user account.
Do I need Microsoft Office?
No. Bitpack creates and reads Word, Excel, PowerPoint and PDF documents by itself, without Office installed. The one exception is the PDF output of Document Merge, which needs Word or LibreOffice.
Where is the data kept?
In a local database in the program's folder, on your computer. Projects, settings and history are not uploaded to a cloud.
Does it work without the internet?
Yes, except the tools that really work with a network: sending e-mail and testing APIs.
Why does it look like Windows 95?
Because the classic interface is clear and easy to learn: windows, menus and buttons that everybody recognizes. Every tool uses it the same way.
